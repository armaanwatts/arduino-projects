## 📌 Project Description

This project demonstrates how to control an LED using a push button.



## 🔧 Components Used

- Arduino Uno
- LED
- Push button
- 220Ω resistor
- 10kΩ resistor
- Breadboard



## ⚡ Circuit Logic

- Button pressed → HIGH signal to Arduino
- Button released → LOW signal
- LED follows button state



## 🧠 Concept Learned

- digitalRead()
- if-else logic
- pull-down resistor



## 🎯 Real-world Use

- Doorbells
- Switch systems
- Basic control panels
