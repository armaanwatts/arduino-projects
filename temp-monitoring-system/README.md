# 🌡️ Temperature Monitoring System (LM35 / DHT11)

## Project Description
This project measures environmental temperature (and humidity if using DHT11) and displays it in real-time using Arduino.

It is a basic version of weather monitoring systems used in IoT devices.

---

## Working Principle

### DHT11 Sensor:
- Digital sensor
- Provides temperature and humidity directly

---

## Components Used
- Arduino Uno
- DHT11 Sensor
- Jumper wires

---

## Circuit Connections

### DHT11:
- VCC → 5V  
- GND → GND  
- DATA → Pin 2  

---

## Concepts Learned
- Analog to digital conversion
- Sensor calibration
- Real-time data monitoring
- Basic IoT data collection

---

## Real-World Applications
