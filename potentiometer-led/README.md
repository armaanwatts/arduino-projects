# LED Brightness Control 🎚️💡


## Project Description
Control LED brightness using a potentiometer.



## Components Used
- Arduino Uno
- LED
- Potentiometer (10kΩ)
- 220Ω resistor



## Working Principle
- Potentiometer gives analog value (0–1023)
- Arduino converts it to PWM (0–255)
- LED brightness changes accordingly



## Concepts Learned
- analogRead()
- analogWrite()
- PWM control
- map() function



## Real-world Applications
- Light dimmers
- Volume control
- Motor speed control
