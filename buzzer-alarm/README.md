# Buzzer Alarm System 

## Project Description
A simple alarm system that produces sound when a button is pressed.

---

## Components Used
- Arduino Uno
- Active/Passive Buzzer
- Push button
- 10kΩ resistor

---

## Working Principle
- Button pressed → Arduino detects HIGH signal
- Arduino sends frequency to buzzer using tone()
- Button released → sound stops

---

## Concepts Learned
- tone() function
- digitalRead()
- event-based control

---

## Real-world Applications
- Security alarms
- Doorbell systems
- Alert systems in devices
