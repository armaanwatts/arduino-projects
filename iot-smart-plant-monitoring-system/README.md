# IoT Smart Environment Monitor

## 📌 Project Description
This system monitors temperature and humidity and sends real-time data to cloud dashboards using ESP8266.

---

## Features
- Live IoT data streaming
- Wireless monitoring
- Cloud integration
- Remote access

---

## Components
- ESP8266 / ESP32
- DHT11 sensor
- WiFi network

---

## Applications
- Smart homes
- Weather stations
- Industrial monitoring
